# 이미지 분석기 v1.3.0

웹에서 이미지를 불러와 AI가 자동으로 분석하고 설명해주는 모바일 웹앱입니다.

## 주요 기능

- 📁 **파일 직접 업로드**: 로컬 이미지 파일을 업로드하여 분석 (CORS 문제 없음!) ⭐ **NEW**
- 🖱️ **드래그 앤 드롭**: 이미지 파일을 끌어다 놓기만 하면 자동 업로드 ⭐ **NEW**
- 🔗 **이미지 URL 입력**: 웹상의 이미지 URL을 입력하여 이미지를 불러옵니다
- 🔍 **AI 이미지 분석**: Claude AI가 이미지를 자세히 분석하고 설명합니다
- 🖼️ **이미지 미리보기**: 분석 전에 이미지를 미리 확인할 수 있습니다
- ⚡ **자동 API 키 설정**: 첫 방문 시 모달로 간편하게 API 키 입력 (한 번만 입력)
- 🔐 **스마트 API 키 관리**: config.js 또는 localStorage에서 자동 로드
- 🔧 **API 키 관리 기능**: 변경, 삭제 버튼으로 쉬운 관리
- 💾 **영구 저장**: 한 번 입력하면 계속 자동으로 사용
- 📱 **모바일 최적화**: 반응형 디자인으로 모바일에서 편리하게 사용 가능

## 설치 및 설정

### 1. API 키 설정

Claude API 키가 필요합니다. [Anthropic Console](https://console.anthropic.com/)에서 발급받을 수 있습니다.

#### 방법 1: config.js 파일 사용 (권장)

1. `config.example.js` 파일을 `config.js`로 복사합니다:
   ```bash
   cp config.example.js config.js
   ```

2. `config.js` 파일을 열고 API 키를 입력합니다:
   ```javascript
   const CONFIG = {
       CLAUDE_API_KEY: 'sk-ant-api03-your-actual-api-key-here'
   };
   ```

3. 웹앱을 열면 자동으로 API 키가 로드됩니다.

> **보안 참고**: `config.js` 파일은 `.gitignore`에 포함되어 있어 Git에 커밋되지 않습니다.

#### 방법 2: 웹 페이지에서 직접 입력 (자동 모달)

config.js를 설정하지 않은 경우:
1. 웹앱을 열면 **자동으로 API 키 입력 모달이 나타납니다**
2. API 키를 입력하고 "저장하고 시작" 버튼을 클릭
3. 입력한 키는 브라우저의 localStorage에 **영구 저장**됩니다
4. 다음 방문부터는 **자동으로 로드**되어 별도 입력 불필요

### 2. 웹앱 실행

#### 로컬 서버 실행

로컬에서 테스트하려면 간단한 HTTP 서버를 실행하세요:

```bash
# Python 3를 사용하는 경우
python3 -m http.server 8000

# Node.js를 사용하는 경우
npx http-server -p 8000
```

그 다음 브라우저에서 접속:
```
http://localhost:8000/s01.html
```

#### 웹 서버에 업로드

`image-analyzer-webapp` 폴더를 웹 서버에 업로드하고 `s01.html` 파일에 접속하면 됩니다.

## 사용 방법

### 첫 방문 시
1. **웹앱 열기**: s01.html 파일을 브라우저에서 엽니다
2. **API 키 입력 모달**: 자동으로 나타나는 모달에 Claude API 키를 입력합니다
3. **저장하고 시작**: 버튼을 클릭하면 API 키가 영구 저장됩니다

### 일반 사용

#### 방법 1: 파일 업로드 (권장 - CORS 문제 없음)
1. **파일 업로드 선택**: "📁 파일 업로드" 버튼이 선택되어 있는지 확인
2. **이미지 선택**:
   - 클릭하여 파일 선택, 또는
   - 이미지 파일을 드래그 앤 드롭
3. **미리보기 확인**: 선택한 이미지가 화면에 표시됩니다
4. **이미지 분석**: "이미지 분석하기" 버튼을 클릭
5. **결과 확인**: AI가 분석한 이미지 설명을 확인합니다

#### 방법 2: URL 입력
1. **URL 입력 선택**: "🔗 URL 입력" 버튼 클릭
2. **이미지 URL 입력**: 분석하고 싶은 이미지의 URL을 입력
   ```
   예: https://picsum.photos/400/300
   ```
3. **이미지 불러오기**: "이미지 불러오기" 버튼 클릭
4. **이미지 분석**: "이미지 분석하기" 버튼을 클릭
5. **결과 확인**: AI가 분석한 이미지 설명을 확인합니다

> **참고**: 파일 업로드 방식은 CORS 문제가 없어 모든 이미지를 분석할 수 있습니다!

### API 키 관리
- **변경**: "API 키 변경" 버튼을 클릭하여 새로운 키 입력
- **삭제**: "API 키 삭제" 버튼으로 저장된 키 제거 (다시 입력 모달이 나타남)

## 문제 해결

### Q: 첫 방문인데 API 키 입력 모달이 안 나타나요
**A**: 이미 API 키가 저장되어 있거나 config.js에 설정되어 있을 수 있습니다. "API 키 삭제" 버튼을 클릭하거나 브라우저의 localStorage를 초기화하세요.

### Q: API 키를 변경하고 싶어요
**A**: 화면의 "API 키 변경" 버튼을 클릭하면 새로운 API 키를 입력할 수 있는 모달이 나타납니다.

### Q: API 키가 자동으로 로드되지 않아요
**A**: 다음을 확인하세요:
- `config.js` 파일이 있고 올바른 API 키가 입력되어 있는지 확인
- 브라우저의 localStorage가 활성화되어 있는지 확인
- API 키가 "sk-ant-"로 시작하는지 확인

### Q: "Failed to fetch" 또는 CORS 오류가 발생해요
**A**: CORS(Cross-Origin Resource Sharing) 정책 때문입니다. 해결 방법:
- **🌟 가장 좋은 방법**: "📁 파일 업로드" 기능 사용 - CORS 문제 완전 해결!
- **권장 이미지 호스팅**: Imgur, Cloudinary, Picsum Photos 등 사용 (URL 방식)
- **테스트 URL**: https://picsum.photos/400/300 (랜덤 이미지)
- **GitHub 이미지**: GitHub 저장소의 이미지 파일 (raw URL)
- **피해야 할 사이트**: Google 이미지, 일부 소셜 미디어 이미지

> **권장**: URL 입력 대신 파일 업로드를 사용하면 모든 이미지를 문제없이 분석할 수 있습니다!

### Q: 이미지를 불러올 수 없어요
**A**: 다음을 확인하세요:
- 이미지 URL이 올바른지 확인
- 이미지가 실제로 존재하는지 확인
- CORS 정책을 확인 (일부 사이트는 외부 접근을 차단합니다)
- 위의 권장 이미지 호스팅 서비스 사용

### Q: API 오류가 발생해요
**A**: 다음을 확인하세요:
- API 키가 올바른지 확인
- API 크레딧이 충분한지 확인
- 인터넷 연결 상태 확인

### Q: 모바일에서 레이아웃이 이상해요
**A**: 최신 버전의 모바일 브라우저를 사용하고 있는지 확인하세요. Safari, Chrome, Firefox 최신 버전을 권장합니다.
