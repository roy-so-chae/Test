Google 최신 동향 검색기

실시간 Google 인기 검색어를 한눈에 확인하세요

v1.0.0

📥 다운로드

단일 HTML 파일로 구성되어 있어 다운로드 후 바로 사용할 수 있습니다. API 키나 설치 과정이 필요 없습니다.

⬇ 웹앱 다운로드 👁 바로 실행하기 💻 GitHub

✨ 주요 기능

실시간 트렌드

Google Trends에서 실시간 인기 검색어를 수집합니다

15개 지역 지원

한국, 미국, 일본 등 주요 국가의 트렌드를 확인

관련 뉴스

각 트렌드의 관련 뉴스 기사와 썸네일 표시

검색량 표시

각 키워드의 대략적인 검색량 확인 가능

설치 불필요

브라우저에서 HTML 파일만 열면 바로 사용

완전 무료

API 키 없이 무료로 사용 가능

🌐 지원 지역

한국 미국 일본 영국 독일 프랑스 인도 브라질 호주 캐나다 대만 이탈리아 스페인 멕시코 러시아

📸 미리보기

📖 사용 방법

  1. 위 다운로드 버튼을 클릭하여 HTML 파일을 저장합니다
  2. 다운로드한 파일을 브라우저에서 엽니다
  3. 드롭다운에서 원하는 지역을 선택합니다
  4. 검색 버튼을 클릭합니다
  5. 인기 검색어를 클릭하면 관련 뉴스를 볼 수 있습니다
