# 🖼️ 배경 회색 → 흰색 변환기

이미지(PNG, JPG, WEBP)의 회색 배경을 깔끔한 흰색으로 자동 변환하는 브라우저 기반 웹 앱입니다.

> 모든 처리는 브라우저에서 수행되며, 서버로 업로드되지 않습니다.

---

## 📥 다운로드

| 방법 | 링크 |
|------|------|
| **파일 직접 다운로드** | [⬇ gray-to-white.html 다운로드](https://raw.githubusercontent.com/roy-so-chae/Test/main/image-analyzer-webapp/gray-to-white.html) (우클릭 → 다른 이름으로 저장) |
| **ZIP 전체 다운로드** | [⬇ ZIP 다운로드](https://github.com/roy-so-chae/Test/archive/refs/heads/main.zip) |
| **Git Clone** | 아래 명령어 참고 |

```bash
git clone https://github.com/roy-so-chae/Test.git
cd Test/image-analyzer-webapp
# gray-to-white.html 파일을 브라우저에서 열기
```

다운로드 후 `.html` 파일을 브라우저(Chrome, Edge, Safari 등)에서 열면 바로 사용할 수 있습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| **드래그 & 드롭** | 이미지를 끌어다 놓거나 클릭하여 업로드 |
| **여러 파일 일괄 처리** | 한 번에 여러 이미지를 변환 |
| **밝기 범위 조절** | 회색으로 판단할 밝기(Lightness) 구간 설정 (기본: 100~240) |
| **채도 허용치 조절** | 채도 기준 — 높이면 약간 색이 있는 배경도 포함 (기본: 30) |
| **경계 부드럽게** | 회색↔비회색 경계를 자연스럽게 블렌딩 (기본: 10) |
| **저장 형식 선택** | PNG / JPG / WebP 중 선택 가능 |
| **원본 vs 결과 미리보기** | 나란히 비교하며 결과 확인 |
| **100% 브라우저 처리** | 서버 업로드 없이 로컬에서 안전하게 처리 |

---

## 🔧 사용 방법

1. **이미지 업로드** — 드래그 & 드롭 또는 클릭하여 파일 선택
2. **슬라이더 조절** — 회색 감지 범위, 채도 허용치, 경계 부드러움을 설정
3. **변환하기 클릭** — 회색 배경이 흰색으로 변환됩니다
4. **다운로드** — 결과물을 원하는 형식(PNG/JPG/WebP)으로 저장

---

## 🎯 활용 예시

- 스캔한 문서의 회색 배경을 깨끗한 흰색으로 정리
- 제품 사진의 회색 배경 제거
- 프레젠테이션/보고서용 이미지 배경 통일
- 쇼핑몰 상품 이미지 배경 보정

---

## ⚙️ 기술 스택

- **순수 HTML/CSS/JavaScript** — 별도 설치 필요 없음
- **Canvas API** — 픽셀 단위 이미지 처리
- **HSL 색상 분석** — 정확한 회색 감지
- **requestAnimationFrame** — UI 블로킹 없는 비동기 처리
- **반응형 디자인** — 모바일/데스크톱 모두 지원
