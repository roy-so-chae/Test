## 📱 프로젝트 목록

### 1. 📰 [Snews - 뉴스 검색 웹앱](./Snews)

**버전**: v1.3.6

영어와 한국어 뉴스를 실시간으로 검색할 수 있는 독립 실행형 웹 애플리케이션입니다.

**주요 기능**:
- 🔍 NewsAPI를 활용한 실시간 뉴스 검색
- 🌐 영어/한국어 뉴스 지원
- 📱 모바일 최적화 반응형 디자인
- 📰 카테고리별 뉴스 필터링
- 🔗 원본 기사 링크 제공

**파일**: `Snews/Snews.html` (단일 HTML 파일)

---

### 2. 🖼️ [이미지 분석기 웹앱](./image-analyzer-webapp)

**버전**: v1.1.0

웹에서 이미지를 불러와 AI가 자동으로 분석하고 설명해주는 모바일 웹 애플리케이션입니다.

**주요 기능**:
- 📸 이미지 URL 입력 및 미리보기
- 🔍 Claude AI를 통한 이미지 자동 분석
- 🤖 이미지 내용, 상황, 특징 설명
- 🔐 API 키 자동 로드 (config.js)
- 📱 모바일 최적화 반응형 디자인

**파일**: `image-analyzer-webapp/s01.html`
